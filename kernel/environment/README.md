# environment

这是一个能力进程被允许看见、被允许碰的那间屋子。它和 process、resource、thread 平级。

进程彼此平级。谁能用什么，看资源句柄。这间屋子不另做一套资源池，也不另做一套线程池。

## 屋子里有什么

工作目录和宿主限制是屋子的架子。七扇门是进程真正用来干活的地方。

- `shell.py`：工作目录、环境变量、输入输出。密钥的值不写进启动包。名字像 KEY、PASSWORD、SECRET、TOKEN 的变量如果直接放在 `env` 里，启动包里也不会留下这个名字。
- `policy.py`：启动最多等多久、停止最多等多久、墙钟、内存、心跳、重启次数。启动和停止的等待仍由进程监督器执行。
- `compute.py`：这间屋子允不允许拉起外面的程序，在哪个目录，最多跑多久。开几个工人、单子分给哪个进程，仍在 `kernel/thread` 和 `kernel/load_balancing`。这里只读它们已经定好的上限，不加减工人，也不挑进程。真要等待命令时，仍由线程去等。没有隔离器时不会直接跑。
- `memory.py`：这个进程能看见哪些页。页仍登记在 `kernel/resource/memory`。没有内存句柄时，这扇门是空的。常驻的可以马上用，换出的按需再取。
- `file_io.py`：读、写、改之前先整理路径，再看它落在不落在允许的地方。
- `filesystem.py`：工作区、临时目录，以及这个能力自己的只读文件。家目录和密钥文件默认不在视野里。
- `identity.py`：身份是进程号和能力名。密钥按名字现取。拉外部程序前先洗掉像密钥的环境变量。放宽文件模式只能升一档，而且只准一次，批准的是用户或策略。
- `communication.py`：记下进程信箱用哪条通道，以及外网清单。送信仍由 `kernel/communication` 做。外网清单这一轮只记录，不掐断模型和网页原来的出口。
- `lifecycle.py`：墙钟到了就要求进程停下。先通知停下，等手里的活做完，宽限过了才由监督器收尾。内存和心跳只提供检查，不做 cgroup。

`room.py` 把这些门拼成一间 `KernelEnvironment`。

## 这一轮谁从屋子走

读文件、写文件、bash，以及模型按名字取密钥。

网页、终端、MCP 仍直接碰系统，留到下一批。
