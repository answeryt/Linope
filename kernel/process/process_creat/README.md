# process_creat

这个目录专门负责进程的创建。

它做三件事：

- 按名字找到能力插件，例如 `model.openai_chat_model`。需要哪种资源由档案函数说明，不在这里猜。
- 把插件路径、资源句柄、运行环境打成一份启动包。
- 用脱离的方式拉起一个进程。一律由 linope 启动这一组文件，并套上运行环境。拉起之后不再持有它的管道或信号关系。

它只负责把进程生出来，不负责之后的停止、崩溃回收，也不决定资源能不能共享。

## 文件

- `__init__.py`：把创建进程时常用的类型和函数集中导出。
- `instances.py`：扫描 `capability` 目录，把插件登记成稳定名字，例如 `model.openai_chat_model`。只记录文件在哪。
- `activation.py`：把「哪个插件、哪些句柄、什么环境」打成一份写进账本的启动包。句柄和需求对不上时，这里会拒绝启动。
- `creator.py`：按账本路径脱离拉起进程，并返回它的 pid。
- `strategy.py`：一律由 linope 启动这一组文件。Windows 上脱离作业对象和控制台，Unix 上新开会话。进程起来后自己读账本，再套用运行环境。
