# process_runtime

这个目录专门负责进程里面跑的程序。

进程启动后从这里进入：自己读账本里的启动包，装上能力插件，如果插件提供了适配器就先初始化，然后进入一个异步优先的进程内运行时。异步适配器直接 `await`，同步插件通过受限线程池执行。没选通道时，通道是账本信箱。停止看进程行上的期望状态，作废句柄看账本里的句柄状态。插件没有适配器时，进程仍能启动，但不能做模型调用这类业务。

命令行在 `kernel/command`。脱离父进程后的入口仍是 `python -m kernel.process.process_runtime.serve`。

## 文件

- `__init__.py`：延迟导出进程对象和启动包，避免和看管进程的目录互相引用时套住。
- `runtime.py`：进程里的主程序。装上插件，有适配器就先初始化，然后由异步运行时认领和处理通道请求；异步插件直接等待，同步插件进入线程池。停止和作废句柄都看账本。
- `serve.py`：脱离启动时的入口。打开账本，读启动包，再进入 `runtime.py`。
- `adapter.py`：插件适配器要具备的三个动作：拿到句柄后初始化、处理一次业务请求、停止前清理。模型调用以后会走这里的业务请求，现在多数插件还没实现它。
