# workspace

工作区是进程租来的一块项目目录。文件、shell、终端靠它看见同一棵项目树，并在读、写、把正文嵌进表示时被拦住。身份是项目根。点名共用时，碰文件的平级进程共用这一份；每个进程只拿自己的句柄，不能拿别人的句柄去开这棵树。

磁盘上的文件还不是上下文。文件躺在项目里不算用量，要等表示嵌进来，才占这张句柄的篇幅。一份很大的项目因此不会一上来就撑满模型能看的内容。换出以后地址还在，只剩链接，用量不再加它。

会一起改的规则分三处，各管一件事：

- 挂载：这张句柄能看见哪些路径、能不能改。家目录、版本库和密钥文件进不去；每个进程有自己的临时目录，别人的临时目录不能读也不能写。这里只交出项目根和档位。外部命令的包装器在 `capability/sandbox`。
- 地址：这张句柄映进来的文件页。没有这张句柄，这一块是空的。
- 用量：这些页里仍嵌着正文的篇幅。上限是句柄上的 `bytes`。到顶就换出、压缩，或拒绝再嵌进新的正文。算法在 [`../account/`](../account/README.md)。

搜索只领 [`../network/`](../network/README.md)，不领这份租约，所以查外网不会顺便拿到项目目录。模型、待办、计划不领挂载。页的三种状态仍在 [`../memory/`](../memory/README.md)。模型说出的话和工具结果由 [`../account/`](../account/README.md) 按各自的链接记账，不在工作区加总。

- [`kind.py`](kind.py)：对外导出种类和身份。实现在 [`mount/kind.py`](mount/kind.py)。
- [`mount/`](mount/README.md)：挂载空间。项目根、可读可写范围、私有临时目录和档位。
- [`address/`](address/README.md)：地址空间。这张句柄映进来的文件页。
- [`usage/`](usage/README.md)：用量说明。计算在 [`../account/`](../account/README.md)，上限是 `bytes`。
