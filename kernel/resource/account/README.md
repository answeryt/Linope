# account

资源用量只在这里算。账本负责记住数字，不负责怎么加。

三种问法，结果一样：已用、上限、单位。没有上限就只报已用。

- `total`：账上全部进程。
- `service`：点名的那些进程。嵌进表示的同一页只加一次。
- `process`：这一个进程。

| 种类 | 已用 | 上限 | 单位 |
| --- | --- | --- | --- |
| `memory`、`workspace`、`tool` | 仍嵌着的页。换出的页不加。按页旁边的链接归到资源 | 句柄上的 `bytes`，没有就不封顶 | 字节 |
| `context` | 这次调用仍占着窗口的 token，输入加输出 | 所调模型的总上下文 | token |
| `network` | 发送字节加接收字节。明细里还有请求次数 | 不封顶 | 字节 |
| `communication` | 送出正文的篇幅 | 不封顶 | 字节 |

内存、工作区、工具从页上现算。上下文、网络、通信在事情发生时记下，跟资源段一起保存。

工作区不再用 `context_budget`。文件能不能再嵌进去，看 `bytes`。

模型不是一种资源。一次回复的输出 token 由模型层交给这里：厂家给了数字就用厂家的，没给就按正文粗算。
